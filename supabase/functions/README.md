# Edge Functions pendientes

Solo para operaciones que requieren entorno confiable, por ejemplo búsqueda limitada de ID público, escaneo/publicación de documentos y eliminación de cuenta. No crear un servidor CRUD paralelo. Ver contrato para nombres/permisos. Verificar JWT, resolver identidad real y autorizar cada recurso antes de usar credenciales privilegiadas. Secretos de Supabase/escáner solo en configuración protegida, nunca Flutter. Escaneo pendiente significa cuarentena, no publicación automática.
