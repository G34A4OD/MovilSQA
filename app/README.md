# Nido · aplicación Flutter

Material 3 en español. Ejecutar flutter pub get, flutter run y flutter test desde esta carpeta. Demo en memoria con datos ficticios; Auth, datos y archivos reales se incorporan con Supabase directo. Ver [estado](../docs/ESTADO.md), [arquitectura](../docs/ARQUITECTURA.md) y [guías del equipo](../equipo/). Validación desde la raíz: scripts/verify.ps1. config/supabase.example.json es solo una plantilla pública para la futura integración; la demo actual no la lee. Nunca añadir claves secret/service_role.
